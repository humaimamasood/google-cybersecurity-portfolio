# Linux Lab 10 - System Investigation and Log Analysis

## Objective

Learn how to investigate a Linux system by checking user information, system status, resource usage, environment variables, logs, and command history.

## Commands Used

```bash
pwd
date
whoami
uptime
df -h
free -h
dmesg | tail
env
ps aux | grep bash
history | tail
```

## Skills Learned

- Check the current working directory
- Display the current date and time
- Identify the logged-in user
- Monitor system uptime
- Check disk usage
- View memory usage
- Examine recent system log messages
- Display environment variables
- Search running processes
- Review recent command history

## Key Concepts

### pwd
Displays the current working directory.

### uptime
Shows how long the system has been running.

### df -h
Displays disk usage in a human-readable format.

### free -h
Displays memory usage.

### dmesg
Displays kernel and system log messages.

### env
Lists environment variables.

### history
Shows previously executed commands.

## Result

Successfully performed a basic Linux system investigation and reviewed important system information and logs.
