# Linux Lab 9 - Process Monitoring

## Objective

Learn how to view and monitor running processes in Linux.

## Commands Used

```bash
ps
ps -A
ps aux
ps aux | grep bash
top
```

## Skills Learned

- View running processes
- Identify process IDs (PIDs)
- View detailed process information
- Search for specific processes
- Monitor processes in real time

## Key Concepts

### `ps`
Displays information about currently running processes.

### `ps -A`
Displays all running processes.

### `ps aux`
Provides detailed information about running processes, including users, PIDs, CPU and memory usage.

### `grep`
Filters process information to find specific processes.

### `top`
Provides real-time process and system monitoring.

## Result

Successfully practiced Linux process monitoring and learned how to investigate running processes.
