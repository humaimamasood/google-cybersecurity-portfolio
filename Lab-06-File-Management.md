# Linux Lab 6 - File Management

## Objective
Learn how to copy, move, rename, and delete files and directories in Linux.

## Commands Used

```bash
mkdir lab6
cd lab6
touch file1.txt
touch file2.txt
mkdir backup
ls
cp file1.txt backup/
mv file2.txt report.txt
mv report.txt backup/
rm file1.txt
mkdir test
rmdir test
```

## Skills Learned

- Create files and directories
- Copy files
- Rename files
- Move files
- Delete files
- Delete empty directories

## Result

Successfully completed Lab 6 and practiced essential Linux file management commands.
