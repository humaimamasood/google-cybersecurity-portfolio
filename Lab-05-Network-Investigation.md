# Linux Lab 5 - Network Investigation

## Objective

Learn how to test network connectivity and retrieve data from the internet using Linux networking commands.

## Commands Used

```bash
cd ~
mkdir network-lab
cd network-lab
pwd
ping -c 4 google.com
curl https://example.com
wget https://raw.githubusercontent.com/github/gitignore/main/README.md
ls
cat README.md
```

## Skills Learned

- Testing network connectivity with `ping`
- Retrieving web content using `curl`
- Downloading files using `wget`
- Verifying downloaded files
- Basic network troubleshooting

## Key Concepts

### ping
Checks whether a remote host is reachable and measures network connectivity.

### curl
Retrieves data from a web server using URLs.

### wget
Downloads files from the internet directly to the local system.

## Result

Successfully tested network connectivity, retrieved web content, and downloaded a file using Linux networking commands.
