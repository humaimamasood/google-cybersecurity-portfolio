# Bash Lab 1 - Hello Bash

## Objective

Learn how to create, make executable, and run a basic Bash script.

## Script

```bash
#!/bin/bash

echo "Hello, Humaima!"
echo "Welcome to Bash Scripting."
echo "This is my first Bash script."

echo "Today is:"
date
```

## Commands Used

```bash
mkdir bash-labs
cd bash-labs
nano hello.sh
chmod +x hello.sh
./hello.sh
```

## Concepts Learned

- Bash shebang (`#!/bin/bash`)
- `echo` command
- `date` command
- Making a script executable with `chmod +x`
- Running a Bash script with `./script.sh`

## Result

Successfully created and executed my first Bash script.
