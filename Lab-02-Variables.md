# Bash Lab 2 - Variables

## Objective

Learn how to create, store, and use variables in Bash scripts.

## Script

```bash
#!/bin/bash

name="Humaima"
role="Cybersecurity Student"
course="Google Cybersecurity"
lab="Bash Lab 2"

echo "Name: $name"
echo "Role: $role"
echo "Course: $course"
echo "Current Lab: $lab"
```

## Commands Used

```bash
cd ~/bash-labs
nano variables.sh
chmod +x variables.sh
./variables.sh
```

## Concepts Learned

- Creating Bash variables
- Assigning values to variables
- Accessing variables using `$`
- Displaying variable values with `echo`
- Using multiple variables in a script

## Result

Successfully created and executed a Bash script using multiple variables.
