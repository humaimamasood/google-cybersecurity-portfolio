# Linux Lab 7 - User and System Information

## Objective

Learn how to identify the current user and gather basic Linux system information.

## Commands Used

```bash
whoami
id
who
echo $USER
echo $HOME
echo $SHELL
hostname
uname -a
cat /etc/os-release
date
cal
uptime
```

## Skills Learned

- Identify the current logged-in user
- View User ID (UID) and Group ID (GID)
- Check logged-in users
- View the home directory
- Identify the default shell
- Find the hostname
- View Linux kernel information
- Check operating system details
- Display date and time
- Check system uptime

## Result

Successfully gathered user and system information using Linux commands.
